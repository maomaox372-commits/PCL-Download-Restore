# Security

**English** | [简体中文](SECURITY.zh-CN.md)

This tool changes an executable. Exact target hashes, paths, backups and recovery integrity are its main boundaries. Only the precise build listed in README is supported.

Do not post keys, accounts or private logs. If this repository enables GitHub Private vulnerability reporting, use Security → Report a vulnerability. Otherwise publish only a request for private contact without exploit details, so the maintainer can arrange a private channel. No unconfigured email address or response deadline is promised.

Provide a minimal isolated reproduction, public version, expected/actual behavior and backup status. Never conduct destructive experiments in your real game directory. See [security warnings](docs/SECURITY-WARNINGS.md). Unsigned status, no antivirus alert, or a single clean scan cannot establish safety.

Updates remain enabled according to the user's existing policy by default. Explicitly disabling them may miss official security fixes or rollbacks; a permanent red warning and [manual instructions](docs/UPDATE-OPTIONS.md) explain the choice. A new build needs fresh EXE and ZIP hashes; old values must not be reused.
