## Implemented measures

1. README, notices, the About page and distribution instructions state independent third-party status.
2. The name begins with PCL and includes a clear third-party suffix.
3. About credits 龙腾猫跃 first with a sponsorship link. Tool source and the unchanged LICENCE are included. Public GitHub availability depends on actual upload status.
4. README and every assistant launch encourage genuine Minecraft and author support. Existing PCL purchase/sponsorship checks remain; this assistant does not launch the game automatically.
5. No sponsorship/theme unlock or similar entitlement is added. Existing PCL permissions are unchanged.

Only five download methods and one visible main-window notice method are changed, on a hash-whitelisted build. No launcher/game/mod binaries or accounts are distributed. Updates and rollbacks can replace the patch by default; there is no background guard or automatic repatching.
